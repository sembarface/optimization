# Многомерные методы оптимизации

В этой папке находятся реализации методов безусловной оптимизации функций нескольких переменных. Все методы работают с вектором начального приближения `x0` и возвращают найденную точку, номер последней итерации и историю движения:

```python
x_star, k, history
```

История `history` используется для визуализации траектории спуска на линиях уровня.

## Общая идея реализации

Большинство методов строят направление движения `d`, после чего решают одномерную задачу поиска шага вдоль этого направления. Для этого используются методы из папки `one_dimensional`:

- `swann` ищет начальный интервал для шага;
- `fib_search` уточняет шаг внутри найденного интервала.

То есть многомерная задача на каждой итерации сводится к одномерной минимизации функции:

```python
phi(t) = f(xk + t * d)
```

или, для метода наискорейшего спуска:

```python
phi(t) = f(xk - t * grad)
```

## Файлы и методы

### `steepest_descent.py`

Метод наискорейшего спуска.

На каждой итерации вычисляется градиент `g = grad(xk)`. Направление движения выбирается противоположно градиенту:

```python
x_next = xk - t * g
```

Шаг `t` подбирается одномерной минимизацией: сначала методом Свенна ищется интервал, затем методом Фибоначчи находится приближенно лучший шаг.

Остановка происходит при малой норме градиента или при малом изменении точки и значения функции.

### `fletcher_reeves.py`

Метод Флетчера-Ривса.

Это вариант метода сопряженных градиентов. В отличие от обычного градиентного спуска, новое направление учитывает предыдущее направление:

```python
dk = -gk + betta * d_pred
```

В этой реализации коэффициент считается так:

```python
betta = (gk @ gk) / (g_pred @ g_pred)
```

После построения направления шаг снова ищется через `swann` и `fib_search`.

### `powell.py`

Метод Пауэлла.

Метод не требует градиента. В начале строится набор направлений на основе единичной матрицы. Затем выполняется последовательная одномерная минимизация вдоль каждого направления.

После прохода по направлениям одно из направлений заменяется на направление общего смещения:

```python
yi - y1
```

Перед заменой проверяется ранг системы направлений, чтобы сохранить независимость направлений.

Этот метод также используется в методах с ограничениями как внутренний безусловный оптимизатор для вспомогательных функций.

### `davidon_fletcher_powell.py`

Метод Дэвидона-Флетчера-Пауэлла.

Это квазиньютоновский метод. Вместо явного вычисления обратной матрицы Гессе поддерживается матрица `A`, которая обновляется после каждого шага.

Направление:

```python
d = -A @ g
```

После перехода вычисляются:

```python
delta_x = x_next - xk
delta_g = g_next - g
```

и по ним строится поправка к матрице `A`. Шаг вдоль направления подбирается одномерной минимизацией.

### `newton.py`

Метод Ньютона.

На каждой итерации вычисляются градиент и матрица Гессе. Если Гессе положительно определена, направление находится из системы:

```python
h @ d = -g
```

Если Гессе не положительно определена, реализация переходит к направлению антиградиента и использует уменьшение шага.

### `newton_raphson.py`

Метод Ньютона-Рафсона.

По структуре похож на `newton.py`, но после выбора направления всегда выполняется подбор шага с условием достаточного убывания. Если Гессе положительно определена, используется ньютоновское направление, иначе направление антиградиента.

В коде также оставлена альтернативная идея поиска шага через `swann` и `fib_search`, но активным является вариант с уменьшением `t`.

### `marquardt.py`

Метод Марквардта.

Это модификация метода Ньютона с регуляризацией матрицы Гессе:

```python
H = h + mu * I
```

Если новый шаг уменьшает функцию, параметр `mu` уменьшается. Если значение функции не улучшилось, `mu` увеличивается, и направление пересчитывается. За счет этого метод может быть устойчивее обычного метода Ньютона.

## Визуализация

Визуализация вынесена в `visualization.py`.

Основные функции:

- `plot_descent` показывает траекторию движения по линиям уровня;
- `plot_surface_descent` строит 3D-поверхность и траекторию для двумерного случая.

## Запуск

Из корня проекта:

```bash
python -m multidimensional.steepest_descent
python -m multidimensional.powell
python -m multidimensional.marquardt
```
