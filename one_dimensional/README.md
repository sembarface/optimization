# Одномерные методы оптимизации

В этой папке находятся реализации методов поиска минимума функции одной переменной. Большинство функций работают с отрезком `[a, b]` и постепенно сужают его до интервала, в котором находится точка минимума.

Общий принцип работы таких методов: на каждой итерации выбираются одна или несколько внутренних точек, значения функции в них сравниваются, после чего часть интервала отбрасывается. История сужения интервала сохраняется в `history`, чтобы потом можно было построить график.

## Файлы и методы

### `uniform_search.py`

Метод равномерного поиска.

В моей реализации отрезок `[a, b]` делится на `N + 1` равных частей. Функция вычисляется в `N` внутренних точках, после чего выбирается точка с минимальным значением. В качестве итогового интервала неопределенности берутся соседние точки вокруг найденного минимума.

Функция возвращает:

```python
xs, fs, xk, interval
```

где `xs` - проверенные точки, `fs` - значения функции, `xk` - лучшая найденная точка, `interval` - интервал вокруг нее.

### `dichotomy.py`

Метод дихотомии.

На каждой итерации около середины текущего отрезка строятся две близкие точки:

```python
y = (a + b - delta) / 2
z = (a + b + delta) / 2
```

Если `f(y) <= f(z)`, правая часть интервала отбрасывается, иначе отбрасывается левая. Цикл продолжается, пока длина интервала больше `2 * eps`.

Возвращается приближение к минимуму и история интервалов:

```python
x_star, history
```

### `interval_halving.py`

Метод деления интервала пополам.

На каждой итерации вычисляются середина интервала `xc` и две точки в четвертях интервала: `y` и `z`. По сравнению значений `f(y)`, `f(xc)` и `f(z)` выбирается новая половина или центральная часть интервала.

В `history` сохраняются не только новые границы, но и точки `y`, `xc`, `z`, чтобы визуализация могла показать, какие точки участвовали в сравнении.

### `gold.py`

Метод золотого сечения.

В реализации используется коэффициент:

```python
phi = (sqrt(5) - 1) / 2
```

На каждой итерации внутри текущего отрезка выбираются две точки `y` и `z`. После сравнения `f(y)` и `f(z)` одна из точек переиспользуется на следующем шаге, поэтому метод требует меньше новых вычислений функции, чем простой перебор.

Метод останавливается, когда длина интервала становится не больше `2 * eps`.

### `fibonacci.py`

Метод Фибоначчи.

Сначала строится список чисел Фибоначчи до значения, достаточного для заданной точности:

```python
L0 = (b - a) / (2 * eps)
```

Дальше интервал сужается по пропорциям, связанным с числами Фибоначчи. Как и в методе золотого сечения, на каждой итерации переиспользуется одна из внутренних точек, а новая точка строится симметрично:

```python
y = a + b - z
z = a + b - y
```

Возвращается середина итогового интервала и история его сужения.

### `swann.py`

Метод Свенна.

Этот метод не ищет минимум напрямую, а подбирает интервал, в котором минимум может находиться. В моей реализации поиск начинается из точки `x0` с шагом `t`. Сначала проверяется направление убывания функции, затем шаг увеличивается как `2**k * delta`.

Метод возвращает:

```python
interval, history
```

Если не удалось определить подходящий интервал, возвращается `None`.

## Визуализация

Графики вынесены в общий файл `visualization.py`.

Используются функции:

- `plot_uniform` для равномерного поиска;
- `plot_halving` для метода деления интервала пополам;
- `plot_one_dim` для дихотомии, золотого сечения и Фибоначчи;
- `plot_swann` для метода Свенна.

## Запуск

Из корня проекта:

```bash
python -m one_dimensional.fibonacci
python -m one_dimensional.gold
python -m one_dimensional.swann
```
