#### Метод барьерных функций

Реализация находится в `constrained/barrier.py`. Метод предназначен для задач с ограничениями-неравенствами `g(x) <= 0` и требует начальную точку внутри допустимой области.

Ограниченная задача преобразуется во вспомогательную безусловную:

```python
F(x, r) = f(x) - r * sum(1 / g(x))
```

На каждой внешней итерации вспомогательная функция минимизируется методом Пауэлла, после чего параметр барьера `r` уменьшается делением на коэффициент `c`. Метод возвращает найденную точку, число итераций и историю внешних итераций для визуализации:

```python
x_star, k, history = barrier(f, constraints, x0, r0, c, eps, M)
```
