# Методы оптимизации с ограничениями

В этой папке находятся реализации методов решения задач оптимизации с ограничениями. Ограниченная задача преобразуется во вспомогательную безусловную задачу, которая затем решается методом Пауэлла из папки `multidimensional`.

Ограничения задаются функцией:

```python
def constraints(x):
    h = np.array([...])  # равенства h(x) = 0
    g = np.array([...])  # неравенства g(x) <= 0
    return h, g
```

Если ограничений какого-то типа нет, возвращается пустой массив:

```python
h = np.array([])
g = np.array([])
```

Все реализации возвращают:

```python
x_star, k, history
```

где `history` хранит внешние итерации метода и используется для визуализации.

## Файлы и методы

### `penalty.py`

Метод штрафных функций.

Идея метода: заменить задачу с ограничениями на безусловную минимизацию вспомогательной функции:

```python
F(x, r) = f(x) + P(x, r)
```

В этой реализации штрафная функция имеет вид:

```python
P(x, r) = r / 2 * (sum(h(x)^2) + sum(max(0, g(x))^2))
```

То есть:

- ограничения-равенства штрафуются через квадрат невязки `h(x)^2`;
- ограничения-неравенства штрафуются только при нарушении, когда `g(x) > 0`;
- коэффициент штрафа `r` постепенно увеличивается умножением на `c`.

На каждой внешней итерации вспомогательная функция минимизируется методом Пауэлла:

```python
xrk, _, _ = powell(Frk, xk, eps, M)
```

Если значение штрафа стало меньше `eps`, метод останавливается. Иначе коэффициент `r` увеличивается, а найденная точка становится новым начальным приближением.

### `barrier.py`

Метод барьерных функций.

Метод используется для задач с ограничениями-неравенствами `g(x) <= 0`. Начальная точка `x0` должна находиться внутри допустимой области, потому что барьерная функция определена только при невырожденных значениях ограничений.

В этой реализации барьерная функция имеет вид:

```python
P(x, r) = -r * sum(1 / g(x))
```

Вспомогательная безусловная задача:

```python
F(x, r) = f(x) + P(x, r)
```

То есть при приближении к границе допустимой области значение барьерной добавки растет и не дает методу выйти за ограничение.

На каждой внешней итерации вспомогательная функция минимизируется методом Пауэлла:

```python
xrk, _, _ = powell(Frk, xk, eps, M)
```

Если значение барьерной функции стало меньше `eps`, метод останавливается. Иначе параметр барьера `r` уменьшается делением на `c`, а найденная точка становится новым начальным приближением.

### `lagrange.py`

Метод модифицированной функции Лагранжа.

Этот метод также строит вспомогательную функцию, но дополнительно использует множители Лагранжа. Для равенств используются множители `lamk`, для неравенств - `muk`.

Вспомогательная функция:

```python
F(x, lam, mu, r) = f(x) + sum(lam * h(x)) + P(x, mu, r)
```

Штрафная часть в этой реализации:

```python
P(x, mu, r) =
    r / 2 * sum(h(x)^2)
    + 1 / (2 * r) * sum(max(0, mu + r * g(x))^2 - mu^2)
```

После минимизации вспомогательной функции методом Пауэлла множители обновляются:

```python
lamk += rk * h
muk = maximum(0, muk + rk * g)
```

Затем коэффициент `rk` увеличивается умножением на `c`.

## Внутренний оптимизатор

Все методы используют `powell` как внутренний метод безусловной оптимизации. Это удобно, потому что для штрафной, барьерной и лагранжевой функций не нужно явно задавать градиент.

## Визуализация

Для двумерных примеров используется функция:

```python
plot_constraint(f, constraints, history, x_star)
```

Она строит линии уровня целевой функции, траекторию точек и линии ограничений:

- красным цветом отмечаются равенства `h(x) = 0`;
- синим цветом отмечаются неравенства `g(x) <= 0`.
