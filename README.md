# Optimization Methods

Это сборник моих реализаций различных методов оптимизации на Python.


## Структура проекта

```text
optimization/
|-- one_dimensional/      # Методы одномерной оптимизации
|-- multidimensional/     # Методы многомерной безусловной оптимизации
|-- constrained/          # Методы оптимизации с ограничениями
|-- visualization.py      # Общие функции визуализации
```

## Реализованные методы

### Одномерная оптимизация

- Равномерный поиск
- Метод дихотомии
- Метод деления интервала пополам
- Метод золотого сечения
- Метод Фибоначчи
- Метод Свенна для поиска интервала неопределенности

### Многомерная оптимизация

- Метод наискорейшего спуска
- Метод Флетчера-Ривса
- Метод Пауэлла
- Метод Дэвидона-Флетчера-Пауэлла
- Метод Ньютона
- Метод Ньютона-Рафсона
- Метод Марквардта

### Оптимизация с ограничениями

- Метод штрафных функций
- Метод барьерных функций
- Метод модифицированной функции Лагранжа

## Зависимости

Для запуска нужны:

```text
numpy
matplotlib
```

## Запуск


```bash
python -m one_dimensional.fibonacci
python -m multidimensional.powell
python -m constrained.penalty
python -m constrained.barrier
```
